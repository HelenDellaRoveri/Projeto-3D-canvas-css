# Projeto 3D com Canvas e CSS

Este projeto foi desenvolvido com o objetivo de **explorar e aprender conceitos de 3D na web** utilizando **HTML, CSS e JavaScript**. Ele apresenta uma animação tridimensional simples criada a partir de transformações CSS e manipulação de elementos em um ambiente gráfico leve e interativo.

> 🔗 **Acesse o projeto online:**
> [https://helendellaroveri.github.io/Projeto-3D-canvas-css/](https://helendellaroveri.github.io/Projeto-3D-canvas-css/)

---

## 🚀 Tecnologias utilizadas

* **HTML5:** estruturação da página e integração com o canvas.
* **CSS3:** transformações 3D, estilização e efeitos visuais.
* **JavaScript (puro):** controle das animações e interatividade.

---

## 🧩 Objetivo do projeto

O principal objetivo foi **experimentar a criação de elementos 3D no navegador**, estudando o comportamento das transformações espaciais e dos efeitos de rotação, perspectiva e profundidade.

Apesar de **não ser um projeto responsivo ainda**, há planos para aprimorar o design e torná-lo adaptável a diferentes tamanhos de tela futuramente.

---

## 💡 Aprendizados

Durante o desenvolvimento deste projeto, foi possível aprender:

* Conceitos básicos de **transformações 3D com CSS** (`rotateX`, `rotateY`, `perspective`, etc.);
* Manipulação de **elementos no espaço tridimensional**;
* Organização e integração entre **HTML, CSS e JavaScript**;
* Estruturação de um projeto estático hospedado no **GitHub Pages**.
